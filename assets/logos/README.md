# Console symbols

Local SVG symbols used in the homepage collection badges. The logos retain their console colours in both themes: multicolour N64, PAL blue Dreamcast, and purple GameCube.

- `n64.svg`: Nintendo's N64 symbol, extracted from [Nintendo 64 (logo).svg](https://en.wikipedia.org/wiki/File:Nintendo_64_(logo).svg). Wordmark removed and bounds tightened; source colours retained. The source identifies this as a copyrighted Nintendo logo.
- `dreamcast.svg`: Sega / Kenji Eno, [Dreamcast swirl.svg](https://commons.wikimedia.org/wiki/File:Dreamcast_swirl.svg), uploaded by Raphaeldrewboltman. Editor metadata removed, given a responsive viewBox, and recoloured using the blue from [Dreamcast logo PAL.svg](https://commons.wikimedia.org/wiki/File:Dreamcast_logo_PAL.svg) to match the PAL collection. Distributed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/), including this adapted SVG.
- `gamecube.svg`: Yoshii Lizcano, [Nintendo GameCube symbol logo.svg](https://commons.wikimedia.org/wiki/File:Nintendo_GameCube_symbol_logo.svg). Unmodified; [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

Console names and logos belong to their respective owners.
