A Game Boy Colour ROM I wrote for testing button inputs.

A simple tool for a familiar handheld.

The project focuses on a basic part of the handheld: its buttons. A dedicated input test gives me a way to check them through software written for the Game Boy Colour.

Code meets the collection.

This is where my work as a software engineer and my interest in retro games come together: writing a ROM with a practical purpose for the hardware I enjoy collecting and working with.
