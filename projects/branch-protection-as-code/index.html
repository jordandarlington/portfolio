Branch Protection
As Code

A GitHub Action that allows users to define and manage branch protection rules as code.

  • TypeScript
  • GitHub Actions
  • GitHub API

Repository configuration, as code.

Branch protection is part of a team's development workflow. Managing those rules as code makes the configuration part of that workflow, too.

This project brings together TypeScript, GitHub Actions, and the GitHub API to automate the management of branch protection rules.

Where it fits

It's an example of the developer tooling I enjoy building: focused automation that helps teams manage the systems around their products.
